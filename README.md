# Лабораторная работа № 3

## Доска публикаций

### Запуск

1. Скачать и распаковать проект.
2. Открыть файл index.html в браузере.
3. Для работы необходим доступ к интернету.

### Реализованный функционал

- Загрузка 5 публикаций через GET-запрос.
- Создание публикации через POST-запрос.
- Проверка заполнения полей формы.
- Отображение публикаций через DOM.
- Обработка ошибок и сообщений о загрузке.
- Повторная отправка запросов после ошибки.

### Результаты проверки

- GET-запрос загружает 5 публикаций.
- Пустые поля формы не отправляются.
- POST-запрос возвращает созданную публикацию и её ID.
- Ошибки отображаются на странице.
- Кнопки снова становятся активными после запроса.
